SeqRename - install
===================

1. Unzip this folder anywhere (Desktop or Downloads is fine).
2. Double-click install.bat.
3. Start SeqRename from the Start Menu.

No administrator rights are needed. Everything goes into your own profile:

  app files   %LOCALAPPDATA%\Programs\SeqRename
  shortcuts   Start Menu and Desktop (current user)
  registry    HKCU only, so it appears in Apps & features

Nothing is written to Program Files, HKEY_LOCAL_MACHINE or the system PATH,
and no service or driver is installed.

Options
-------

  install.bat -NoDesktopShortcut          skip the desktop shortcut
  install.bat -InstallDir D:\Tools\SeqRename
  install.bat -Quiet                      no console output
  install.bat -Uninstall                  remove it again

Notes for networked workstations
--------------------------------

Install to a local disk. %LOCALAPPDATA% is local on a standard profile, and the
app loads ~110 MB of Qt libraries at startup - running it from a network share
is noticeably slower.

If the profile is redirected so that %LOCALAPPDATA% lives on a share, pass a
local path instead:

  install.bat -InstallDir C:\Users\Public\SeqRename

The installer clears the "downloaded from another computer" mark that Windows
puts on files copied over a network, which is the usual cause of a blocked
launch after copying a build across.

Uninstall
---------

Apps & features -> SeqRename -> Uninstall, or run Uninstall.bat from the
install folder.
